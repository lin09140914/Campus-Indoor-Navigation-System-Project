## 2. 各階段驗收標準

| 階段 | 驗收標準 |
| --- | --- |
| 11/29 | 使用者可從統一目的地資料選擇目標及移動方式；WebView 能顯示 3D 組提供的單層地圖。 |
| 12/06 | 可依序取得定位、選擇目的地與模式、取得 Route 並顯示地圖及路線；跨樓層時可手動切換 Route 經過的樓層，地圖與路徑同步更新。定位不可用時，測試起點必須明確標示。 |
| 12/11 | 完成端到端導航操作；未選目的地、定位失敗、無可達路徑、圖資缺失及渲染失敗均有可理解的提示，App 可繼續操作。 |

## 3. 需要實作的功能

- 以 Android UI 提供目的地及 `any`、`stair`、`elev` 移動方式選擇。
- 整合定位組 `getCurrentPosition()` 與路徑組 `findRoute()`，將結果交給 3D 組 `renderMap()`、`renderRoute()` 顯示於 WebView。
- 提供經過樓層的手動切換控制，讓地圖與路徑片段同步顯示。
- 將跨組異常狀態轉成使用者可理解的提示與後續操作。
