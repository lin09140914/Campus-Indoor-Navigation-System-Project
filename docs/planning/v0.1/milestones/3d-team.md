## 3. 需要實作的功能

- 使用 Three.js 實作 `renderMap()`，依統一 SVG 與樓層資料建立可旋轉的單層／多層場景。
- 實作 `renderRoute()`，將 Route 正確疊加在場景中，並清除舊路線。
- 支援由 UI 指定顯示樓層，保持地圖、路徑與共通座標一致。
- 提供 Android WebView 可使用的渲染介面與錯誤狀態。
