# 定位組 V0.1 開發進度表

## 1. 建議開發進度

| 截止日期（2026 年） | 交付項目 | 最低完成要求 |
| --- | --- | --- |
| 11/29 | 感測資料與定位介面 | 讀取 Android 手機的實際感測資料，確認定位方法可行，確立統一 Localization Result 輸出。 |
| 12/02 | 初版自動定位 | 交付可呼叫的 `getCurrentPosition()`，在使用者原地時以實際感測資料估計位置，供路徑組測試。 |
| 12/04 | 定位驗證 | 測試座標、樓層與 confidence，並與路徑組的節點匹配流程串接。 |

## 2. 各階段驗收標準

| 階段 | 驗收標準 |
| --- | --- |
| 11/29 | 實機可取得所選方法需要的感測資料；輸出格式、座標系統及樓層欄位與共通資料規格一致。 |
| 12/02 | 不手動指定起點即可回傳原地位置估計；資料不足或定位失敗時回報失敗，不捏造座標或 confidence。 |
| 12/04 | 在已知測點比較實際與估計位置，檢查樓層及 confidence，並確認路徑組能使用定位結果進行節點匹配。 |
| 12/11 | 保存測點、估計位置、誤差及多次測試統計；定位誤差合格門檻與測點數量待正式訂定。展示用測試起點不算自動定位驗收通過。 |

## 3. 需要實作的功能

- 取得及處理定位所需的手機感測資料，完成原地自動定位演算法。
- 實作 `getCurrentPosition()`，輸出統一 Localization Result，包括位置、樓層、confidence 與時間戳記。
- 將定位結果對應至共通座標系統，並處理權限拒絕、感測資料不足及定位失敗。
- 執行實地定位精準度測試，產生誤差紀錄與報告。
