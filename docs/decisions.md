```

```

## （填入日期）建築由數學館改為工程五館
- 決定：第一版的目標建築是工程五館（Engineering Building #5），不再是進度報告裡的數學館。
- 原因：新加入的組員都是資工系同學，工程五館他們較熟悉，也較容易到現場。
- 影響哪些組：全部。平面圖要向工程五館所屬單位申請；房號格式以現場為準；到現場看過之後，再決定第一版先做哪一層或哪一個區域。需要先通知老師。
