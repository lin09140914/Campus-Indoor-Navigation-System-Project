# 校園室內導航系統 V1 — 地圖組開發規格書

**文件版本：** V0.1（草案）  
**負責組別：** 地圖資料組（Map Team）  
**適用範圍：** V1  
**狀態：** 待跨組資料規格確認

---

## 1. 開發目標

地圖組負責建立校園建築物的室內地圖資料，提供其他組別進行定位、導航路徑計算及 3D 視覺化。

本組 V1 的核心任務為：

1. **建立並交付統一格式的地圖資料：** SVG 平面圖、Graph 導航圖與節點對應表。
2. **實作建圖誤差評估程式：** 驗證地圖與實際建築空間之間的位置、距離及比例誤差。

地圖組不負責導航演算法、手機定位演算法、3D 渲染或 UI 開發。

## 2. 工作範圍與交付成果

| 工作項目 | 交付成果 | V1 要求 |
| --- | --- | --- |
| 樓層平面圖建立 | 統一 SVG 平面圖 | 必須 |
| 導航圖建立 | 統一 Graph | 必須 |
| 節點與實際地點對應 | 統一節點對應表 | 必須 |
| 建圖誤差評估 | 誤差評估程式及測試報告 | 必須 |

三種地圖資料應對應相同的建築空間，並遵守全專案共通的座標、樓層與 ID 規範。

## 3. 主要 Function 規格

### 3.1 evaluateMapError()

**功能：** 評估地圖資料相對於實際量測資料的誤差。

| 項目 | 規格 |
| --- | --- |
| Function 名稱 | `evaluateMapError()`（暫定） |
| Input 1 | 地圖資料 |
| Input 2 | 實際量測參考資料 |
| Output | 建圖誤差評估結果 |
| 使用對象 | 地圖組測試與驗收 |
| 使用時機 | 建圖完成及地圖修改後 |

誤差評估內容應涵蓋實際量測與地圖座標或距離的差異，並產生可供審查的結果。

具體參數型別、誤差計算公式、合格門檻及報告格式，後續確認。

本 Function 屬於地圖資料的離線測試工具，不要求 UI 組於導航執行期間呼叫。

## 4. 統一資料規格

### 4.1 SVG 平面圖

**資料提供者：** 地圖組  
**主要接收者：** 3D 組

必須符合全專案統一 SVG 規格，包括：

- 各樓層平面圖的空間結構。
- 一致的圖面尺寸、比例與座標轉換規則。
- 樓層識別及圖面對應關係。
- 能供 3D 組正確建立樓層地圖。

### 4.2 Graph 導航圖

**資料提供者：** 地圖組  
**主要接收者：** 路徑組

必須符合統一 Graph 規格，包括：

- 導航節點及節點位置。
- 節點間的連接關係。
- 邊的權重與通行方式。
- 跨樓層的樓梯及電梯連接關係。

Graph 必須能供路徑組執行 A\* 路徑規劃。

### 4.3 節點對應表

**資料提供者：** 地圖組  
**主要接收者：** 路徑組、UI 組

必須建立實際地點與導航節點之間的對應關係，包含：

- 導航節點識別資訊。
- 房間或目的地識別資訊。
- 地點所屬樓層。
- 地點與導航節點的對應關係。

### 4.4 共通資料一致性

三份資料必須遵守相同的座標與識別標準，尤其需要確認：

- 同一位置在 SVG 與 Graph 中具有一致的空間意義。
- 節點對應表引用的 Graph 節點確實存在。
- 樓層、地點 ID 與相關資料互相對應。
- 地圖修正後，所有受影響的資料同步更新。

**本節具體欄位、型別與檔案格式以後續正式發布的八項統一資料規格為準。**

## 5. 跨組交接

| 接收組 | 交付資料 | 用途 |
| --- | --- | --- |
| 3D 組 | SVG、相關樓層及座標資料 | 單層／多層地圖渲染 |
| 路徑組 | Graph、節點對應表 | 路徑規劃及地點匹配 |
| UI 組 | 地點／節點對應資料 | 使用者選擇目的地 |
| 定位組 | 共用座標及必要地圖參考資訊 | 讓定位結果能對應地圖 |

各組使用的資料必須符合相同版本的共通資料契約。

## 6. 開發環境與依賴

地圖組可以自行決定地圖繪製、資料整理與誤差測試所需的程式語言及工具。

開發限制：

- IDE 自由選擇。
- 交付的資料必須符合統一跨組規格。
- 不得自行修改已定案的座標系統及共用資料結構。
- 新增依賴與開發流程必須遵守專案開發規則。
- 誤差評估程式必須提供執行及使用說明。

實際工具、依賴名稱與版本待地圖組確認。

## 7. 測試與驗收要求

### 7.1 地圖資料驗收

| 測試項目 | 驗收方向 |
| --- | --- |
| SVG 完整性 | 必要樓層與地圖元素正確呈現 |
| Graph 正確性 | 導航節點及邊的連接符合實際可通行空間 |
| 節點對應表 | 地點與導航節點對應正確 |
| 座標一致性 | SVG、Graph 與實際位置符合共同座標規範 |
| 跨樓層連接 | 樓梯及電梯的樓層連接資訊正確 |

### 7.2 建圖誤差評估

必須使用實際參考量測資料進行測試，並保存：

- 測試位置或測試區域。
- 實際量測值與地圖對應值。
- 計算得到的誤差。
- 誤差統計與測試結論。

具體誤差門檻與測試數量後續制定。

## 9. V1 完成條件

地圖組完成 V1 必須達成：

1. 交付統一規格的 SVG、Graph 與節點對應表。
2. 三份資料相互一致，並能供相關組別使用。
3. 完成建圖誤差評估程式。
4. 提交實際測試結果，達到後續確認的驗收標準。
5. 遵守專案統一的開發與資料規範。

其他內部函式、演算法與開發工具由地圖組自主決定。
